# 📊 Customer Churn Analysis

## 📖 Project Overview
This project analyzes customer churn using Python, SQL, and Power BI. The goal is to identify customer churn patterns and generate business insights through data analysis and dashboards.

## 🎯 Objectives
- Analyze customer churn data
- Clean and preprocess the dataset
- Perform Exploratory Data Analysis (EDA)
- Execute SQL queries for insights
- Build an interactive Power BI dashboard
- Provide business recommendations

## 🛠️ Technologies Used
- Python
- SQL
- Power BI
- Pandas
- NumPy
- Matplotlib

## 📂 Project Files
- cleaned_customer_churn.csv
- customer_churn_analysis.ipynb
- customer_churn_analysis.sql
- Customer_Churn_Dashboard.pbix

## 📈 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Dashboard Development
6. Business Insights
